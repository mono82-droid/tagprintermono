# 택번호 프린터 (웹 · 아이폰용)

Xprinter XP-365B 로 연속 택번호를 인쇄하는 웹페이지. 안드로이드 앱(TagPrinter)과 같은 기능.

## 아이폰에서 쓰는 법
1. App Store에서 **Bluefy – Web BLE Browser** 설치 (사파리·아이폰 크롬은 웹페이지에서 블루투스를 못 씀)
2. Bluefy에서 이 페이지 주소 열기
3. 상단 프린터 상태 칸 → **프린터 찾기** → XP-365B 선택 (또는 바로 [인쇄]를 누르면 고르는 창이 뜸)

## 기능
- 탭: 라벨마다 하나씩 (글자 · 연속번호 · 날짜), 위 ＋로 추가, 길게 누르면 이름·크기·복제·삭제
- 글자를 누르면 바로 수정, 위치 고정 / 끌어서 이동, 가로·세로 가운데 고정
- 글꼴 18종 + TTF/OTF 추가, 크기 자동 맞춤(라벨 밖으로 안 나감), 꽉 채우기, 장평, 굵게·기울임·밑줄·반전, 회전
- 연속번호: "7-404"처럼 입력하면 끝 숫자만 증가, 다음 번호 · 장수 · 번호 범위
- 쉬지 않는 연속 인쇄, 첫 장 미리 만들기, 끊기면 자동 재연결, 중간에 끊겨도 이어서 인쇄
- 최근 인쇄(그림으로), 되돌리기/다시 하기
